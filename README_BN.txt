EARNOVA — DEMO WEBSITE

এটি একটি সাধারণ স্ট্যাটিক ডেমো ওয়েবসাইট।
এতে আছে:
- Earnova হোমপেজ
- নমুনা ড্যাশবোর্ড
- ডেমো পয়েন্ট
- নমুনা উইথড্র রিকোয়েস্ট ফর্ম

গুরুত্বপূর্ণ:
এটি এখনো আসল earning website নয়। কোনো আসল offerwall, user database,
admin login, wallet, বা payment gateway যুক্ত নেই। এখানে টাকা আয় বা
উত্তোলন করা যাবে না। বাস্তব ব্যবহারকারীর তথ্য সংগ্রহ করবেন না।

লোকালি দেখতে:
index.html ফাইলটি Chrome-এ খুলুন।

GitHub-এ আপলোড:
ZIP extract করে ভেতরের index.html, static ফোল্ডার এবং README_BN.txt
আপনার GitHub repository-তে আপলোড করুন। ZIP ফাইলটিকে extract না করে
repository-তে দিলে সাইটটি সরাসরি প্রকাশ হবে না।

পরবর্তী ধাপ:
বাস্তব সাইট চালুর আগে নিরাপদ backend, database, admin authentication,
offer provider agreement, fraud checks এবং payment integration তৈরি
ও পরীক্ষা করতে হবে।
